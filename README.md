
# Tardigrade Explorer

Projet scientifique interactif sur les tardigrades et les protéines impliquées dans la cryptobiose.

## Objectifs

- Explorer les protéines liées au stress.
- Présenter les différents types de cryptobiose.
- Visualiser des structures moléculaires en 3D.
- Comparer les données d'expression des protéines.

## Technologies

- Python
- Django
- HTML, CSS et JavaScript
- Git et GitHub
